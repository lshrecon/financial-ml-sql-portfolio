2026年10月9日版。修正・学習用コピーから整理した採用検討用ソースです。元の授業提供資料は同梱していません。全ノートブックを一括実行できる完成パッケージではありません。

## 目的・構成

授業・教員から提供された財務・株価データを加工し、PER・PBR・PSR・PCRの逆数、平均、順位を使って決定木とランダムフォレストで分類した個人制作です。最近はAIの支援で計算と評価を再点検しました。

- 現在の分類対象は、調整後株価の上昇・非上昇です。口座損益と残金は別に計算します。
- `ml_validation.py`：残金・利益・価格方向、時間順分割の共通処理。
- `KSE_가치팩터_functions.py`：指標、順位、価格取得、集計。
- `evaluate_price_direction.py`：v2の限定的な価格方向の評価。`evaluate_saved_cohort.py` は以前の口座利益目標の評価・回帰検査用です。
- 3冊のMLノートブック：前処理と元の実験構成を読むための参考ソース。
- `database/stock_etl.py` とSQL：pandasでの整形、MySQLのテーブル設計・取込・年別抽出。MLはExcel入力で、DBからモデルへの自動連携は行っていません。

## 修正例：残金は利益ではない

元金1,000で単価300の株を3株買い、330で売った場合、残金は100、株の差益は90です。以前は90に残金100を加えて利益190としていました。修正後は最終資産1,090から元金1,000を引いて利益90とし、残金は利益に加えず、資産として保持します。

元金500・株価600→660なら購入は0株、口座利益は0ですが、価格方向の正解は上昇です。二つの目的を同じ正解にしないよう分離しました。年度と会社の対応、月外の日付、空の結果、PBR年度の取り違えも修正しました。

## 小さな検査の入口

確認済みのML環境はPython 3.12.7、NumPy 1.26.4、pandas 2.2.2、scikit-learn 1.7.0です。検査にはmatplotlib、Excel読込にはopenpyxlも必要です。新規環境のインストールは検証していません。

```text

python -m unittest discover -s database -p test_stock_etl.py -v
```

元資料がないため、このZIPだけでは実データ学習・378万行の照合を再現できません。実MySQLの11検査はMySQLサーバーの別途準備と設定が必要で、上のPython検査には含まれません。`sample_stock_data.csv` は仮の会社3行の合成資料です。`run_isolated_mysql.py` はWindowsのMySQLバイナリ等を別途用意する場合の参考です。
